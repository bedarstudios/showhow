Showhow

Design system

A calm, paper-and-ink system for turning screen recordings into step-by-step guides. Cream surfaces, charcoal ink, one sage accent. Mono labels do the talking; colour marks state, never decoration. Source of truth: design/showhow.pen.

Foundations

Colour

Light theme
Dark theme
Dark panel (sidebar, video, guide shots) — same in both themes
Fixed colours — recorder bar & editor

ds-accent (sage) is the only accent: primary actions, the selected library row, progress, and the guide's "made by" markers. ds-rec marks recording and errors only — always next to a text label. The recorder bar (ds-hud-*) and editor (ds-editor-*) keep their own fixed dark palette. Every colour in a screen must be a ds-* variable; the logo is the only fixed-hex exception.

Typography

Inter Tight (ds-font-display) — screen titles, recording names, section headings. Inter (ds-font-body) — paragraphs, step titles, row titles. JetBrains Mono (ds-font-label), uppercase with 0.06em tracking — buttons, tags, meta lines, timestamps, section numbers and paths. Instrument Serif italic (ds-font-serif) — only for quoted narration inside guide steps.

Buttons

Button/Primary sage — one per view, the main action (New recording, Create guide). Secondary chip — Export PDF, Copy path. Dark — the hand-off action (Copy for agent, Save step). Ghost — Remake, Cancel. Toolbar — icon-first actions in dense rows. Sidebar — actions on the dark panel. All buttons: 4px corners, 14px lucide icon (can be switched off), mono uppercase label.

Showhow turns what you clicked and said into steps, on this Mac. No account or API key.

Empty states — one Inter Tight heading, one muted sentence naming what will appear, one primary button naming the action. Nothing else. Progress lives inline in a Card, never in a modal.

Voice

Buttons name the action — New recording, Create guide, Copy for agent — never a bare "OK."
Toasts say what happened, without "successfully" — Copied folder path.
Empty states point to the next action — "Pick a recording, or start a new one."
In-progress uses a present participle and an ellipsis — "Making guide…"
Sentence case everywhere; mono labels are uppercased by style, not typed in caps.
It's a guide, not a "workflow doc" or "AI guide". Say where work happens: on this Mac.

Do / Don't

Do keep surfaces cream and ink charcoal — never pure white or pure black.
Do use ds-* variables for every colour so dark mode works.
Do pair the red recording dot with a text label; colour alone never signals state.
Don't use more than one sage primary button per view.
Don't use sage or red decoratively.
Don't mix light and dark theme values in one view (the dark panel is part of both themes).
Don't build a one-off button or tag — use the component.
